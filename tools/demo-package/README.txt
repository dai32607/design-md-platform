============================================================
  DESIGN.md 设计规范平台 —— Windows 离线演示包
============================================================

一、快速开始
   1. 将整个 DesignMD-Demo 文件夹解压到本地磁盘（例如桌面或 D 盘）。
      注意：请先解压再运行，不要在压缩包内直接双击运行。
   2. 双击「启动演示.bat」。
   3. 等待约 10 至 20 秒，程序会自动打开浏览器访问 http://localhost:8080
      （若 8080 端口已被占用，会自动改用 8090 端口，并在窗口中提示）。
   4. 演示结束后，请双击「停止演示.bat」停止服务：它会停止服务，并把演示数据
      自动复位为初始状态。直接关闭标题为「DESIGN.md 演示服务」的窗口也能停止
      服务，但不会复位数据。

二、演示账号（仅限本离线演示库，切勿用于任何线上环境）
   - 普通用户：test / see-local-config
   - 管理员：admin / see-local-config
   - 演示库为本地 H2 文件库，账号仅供现场演示登录，与任何真实系统无关。

三、环境要求
   - 完全离线自包含：无需安装 JDK / MySQL / Node.js，也无需联网。
   - 支持系统：Windows 10 / 11（64 位）。
   - 内置数据库为 H2 文件库，数据文件位于 data 目录，演示过程中的新增、修改
     会保存在其中；双击「停止演示.bat」停止服务时，会先把当前演示数据备份到系统
     临时目录（%TEMP%\DesignMD-Demo-backup，仅保留最近一份），再自动清理 data
     目录的运行期残留并把演示数据库还原为初始基线，便于反复演示。

四、目录说明
   启动演示.bat   启动服务并自动打开浏览器
   停止演示.bat   停止后台服务进程，并把演示数据复位为初始状态
   app\           程序主文件（design-md-platform.jar）
   runtime\       内置精简版 Java 21 运行环境（请勿删除）
   data\          演示数据库文件（24 个品牌、1331 条设计 Token 等预置数据）
                  design_db.mv.db.bak 为初始基线，供「停止演示.bat」复位时使用
   uploads\       演示时上传的 LOGO / DESIGN.md 文件存放目录（可写）

五、常见问题
   1. 双击后窗口一闪而过？
      请确认文件夹结构完整（app、data、runtime、uploads 四个目录齐全），
      不要只单独拷贝 .bat 文件。
   2. 浏览器没有自动打开？
      手动打开浏览器访问 http://localhost:8080（或窗口提示的 8090 端口）。
   3. 提示端口被占用？
      脚本会自动切换到 8090 端口；若仍无法访问，先运行「停止演示.bat」再重新启动。
   4. 想恢复初始演示数据？
      双击「停止演示.bat」即可：停止服务后会自动清理 data 目录的运行期残留
      （如 *.lock.db），并把 design_db.mv.db 还原为初始基线。
      如需手动处理：关闭演示服务后，删除 data 目录下的 design_db.mv.db，
      再把同目录下的 design_db.mv.db.bak 复制一份并改名为 design_db.mv.db 。
